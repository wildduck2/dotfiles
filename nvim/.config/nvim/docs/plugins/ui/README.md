# ui

Interface chrome: statusline, file tree, terminal toggle, zen mode, which-key,
snacks indent helper.

| Module | What | Link |
| --- | --- | --- |
| lualine | Status line | [lualine](lualine/README.md) |
| snacks | `folke/snacks.nvim` (we only enable `indent`) | [snacks](snacks/README.md) |
| which-key | `<leader>` popup with group labels | [which-key](which-key/README.md) |
| toggleterm | Tabbed/floating terminal | [toggleterm](toggleterm/README.md) |
| zen-mode | Distraction-free single-window mode | [zen-mode](zen-mode/README.md) |
| nvim-tree | File tree sidebar (left, width 45) | [nvim-tree](nvim-tree/README.md) |
