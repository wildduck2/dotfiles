# lang

Language-specific tooling. `init.lua` here flattens nested spec lists, so a
module file can return either one spec or a list of specs.

| Module | What | Link |
| --- | --- | --- |
| treesitter | nvim-treesitter (main) + treesitter-modules + textobjects | [treesitter](treesitter/README.md) |
| autotag | nvim-ts-autotag: auto-close/rename JSX/HTML/Vue tags | [autotag](autotag/README.md) |
| clangd-extensions | AST view, memory usage, symbol info for clangd | [clangd-extensions](clangd-extensions/README.md) |
| dadbod | DataGrip-style SQL workflow: dadbod + UI + db_manager + cmp completion | [dadbod](dadbod/README.md) |
| markdown | obsidian.nvim, mdx.nvim, peek.nvim live preview | [markdown](markdown/README.md) |
| package-info | inline package.json version info | [package-info](package-info/README.md) |
| rust | rustaceanvim + rust.vim (rust-analyzer with Rust-specific keymaps) | [rust](rust/README.md) |
